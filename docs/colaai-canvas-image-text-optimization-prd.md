# ColaAI 图文画布优化 PRD

版本：v0.2
日期：2026-05-31
范围：ColaAI 画布的文本节点、图片节点、图片派生工作流与切换动画
参考对象：Liblib 画布图文节点体验

## 1. 背景

当前 ColaAI 画布已经具备基础节点与生成能力，但图文节点的“工作流感”和“状态切换感”还可以继续增强。Liblib 的核心优势不只是功能数量，而是把复杂生成流程拆成了清晰的画布状态：

- 浏览态：节点轻量、干净，只展示核心结果和少量快捷入口。
- 编辑态：节点展开 prompt、参数、模型、素材引用等高密度配置。
- 结果态：图片结果上方出现派生工具条，引导用户继续扩展工作流。
- 派生态：点击高清、九宫格、多角度等能力后，自动创建新节点并连线。

本 PRD 目标是把这些优点抽象为 ColaAI 可落地的图文画布优化方案，不包含视频生成能力。

## 2. 产品目标

1. 让 ColaAI 的文本节点和图片节点从“表单式生成”升级为“画布式创作工作流”。
2. 提升节点状态切换的流畅度，让创建、编辑、收起、选中、派生都有明确动画反馈。
3. 强化图片节点的后续创作能力，让图片结果可以继续派生高清、九宫格、多角度、打光等后处理节点。
4. 引入素材库、历史记录、prompt 辅助 chip、参数栏等能力，降低用户组织图文创作素材的成本。
5. 保持画布整洁：默认轻量展示，只有在选中或编辑时展示高密度控件。

## 3. 非目标

- 不做视频生成、视频合成、音频生视频等视频相关功能。
- 不强制复刻 Liblib 的品牌视觉，只复刻其对 ColaAI 有价值的交互结构。
- 不在首期实现真实模型调用的全部后处理能力，可以先完成 UI、状态流和节点工作流骨架。
- 不把所有参数永久铺开在画布上，避免画布变成复杂表单页。

## 3.1 全局视觉主题约束

后续所有即将修改或新增的 UI，都必须符合当前 ColaAI 画布主题。Liblib 只能作为交互结构、功能组织和状态动画参考，不作为最终视觉风格的直接复制对象。

当前 ColaAI 画布主题基调：

- 画布整体保持轻量、清爽、空间感明确，优先使用当前浅色画布、柔和网格/纹理、玻璃感浮层和低对比阴影。
- 节点卡片延续现有 ColaAI 的圆角、白色/半透明表面、slate 文本、violet/cyan 点缀、轻量描边和柔和 hover 反馈。
- 高密度编辑面板可以借鉴 Liblib 的深色 prompt 面板，但必须做 ColaAI 化处理：尺寸、圆角、阴影、按钮形态、色彩对比和字体层级要与当前画布融合。
- 工具条、参数栏、弹层、菜单、派生节点、素材/历史面板都应看起来属于同一个 ColaAI 画布系统，不能出现孤立的外站风格拼贴。
- 动画应服务于 ColaAI 的“轻、顺、清楚”体验，避免过度炫技、强霓虹、重发光或与当前画布不协调的强暗黑质感。

设计执行规则：

- 新增 UI 前必须先观察当前画布已有组件：顶部标题区、左侧导航、底部工具条、小地图、节点卡片、生成配置节点、连接线。
- 任何借鉴 Liblib 的 UI，必须先抽象为 ColaAI 版本，再落到代码中。
- 不允许因为参考 Liblib 而破坏 ColaAI 当前的视觉系统、信息层级和交互节奏。
- 如果某个功能需要临时使用深色面板，应保证它只作为编辑态/强调态出现，默认浏览态仍以 ColaAI 画布的清爽主题为主。

## 4. 用户画像与核心场景

### 4.1 目标用户

- 使用 ColaAI 做图文创作的普通用户。
- 需要从文字脚本生成图片、再对图片进行后处理的创作者。
- 需要管理素材、引用历史图片、反复调整 prompt 和参数的高频用户。

### 4.2 核心场景

1. 用户双击画布，选择创建文本节点，输入故事/角色/场景设定。
2. 用户从文本节点继续派生图片节点，或直接双击画布创建图片节点。
3. 用户在图片节点中输入 prompt，选择模型、比例、清晰度、镜头/摄像机、生成张数、联网搜索等参数。
4. 图片生成后，用户选中图片结果，通过上方工具条继续派生高清、九宫格、多角度、打光等节点。
5. 用户从素材库或生成历史中引用图片/角色/场景/风格素材，加入当前图片 prompt。

## 5. 信息架构

### 5.1 画布层

- 延续当前 ColaAI 主题的无限画布背景，不另起一套外站视觉。
- 点阵/网格纹理，提供空间感但不能干扰节点内容。
- 左侧浮动工具栏：添加节点、工具箱、素材、历史、教程、客服。
- 底部画布控制：整理画布、小地图、网格吸附、缩小、缩放比例、放大。
- 顶部项目区：Logo、项目名、同步状态、分享/积分入口。

### 5.2 节点创建菜单

触发方式：

- 双击空白画布。
- 点击添加节点按钮。

菜单结构：

- 添加节点：文本、图片、视频、视频合成、导演台、音频、脚本。
- 添加资源：上传、从生成历史选择。

ColaAI 首期只实现或突出：

- 文本。
- 图片。
- 上传。
- 从生成历史选择。

菜单每个选项需要包含：

- 图标。
- 主标题。
- 副说明。
- Beta/New 标记，若有。

## 6. 文本节点需求

### 6.1 文本节点浏览态

文本节点默认以紧凑卡片显示：

- 标题：文本节点 + 编号。
- 中间占位或文本摘要。
- 快捷尝试能力：
  - 自己编写内容。
  - 文生图片。
  - 图片反推提示词。
  - 文字生音乐可先隐藏或降级，不作为图文主链路。

浏览态应尽量克制，只展示节点身份、摘要和少量快捷入口。

### 6.2 文本节点编辑态

进入方式：

- 新建文本节点后自动进入。
- 点击/双击文本节点。
- 点击节点快捷入口“自己编写内容”。

编辑态布局：

- 上方保留小文本节点卡片。
- 下方展开大 prompt 输入面板。
- prompt 面板与节点卡片视觉关联，但不塞进卡片内部。

输入面板内容：

- 大号 contenteditable / textarea 输入区。
- placeholder 示例：`写下你想讲的故事、场景或角色设定。例如：一个来自未来的机器人，在城市屋顶看星星。`
- 左下角模型选择器。
- 右下角翻译提示词按钮。
- 右下角消耗点数。
- 右下角生成按钮。

### 6.3 文本模型选择器

模型按钮点击后弹出模型菜单：

- 当前模型高亮。
- 每个选项包含图标、模型名、副标题、预计耗时。
- 示例选项：
  - GVLM 3.1，20s，多模态文本模型 Pro。
  - CVLM 5.5，10s，超智能大语言模型。
  - GVLM 3.1 Flash，15s，多模态文本模型 lite。
  - Qwen 3 VL Flash，10s。

验收标准：

- 空 prompt 时生成按钮禁用。
- 输入 prompt 后生成按钮亮起。
- 切换模型后按钮文案/预计耗时/消耗点数可联动更新。

## 7. 图片节点需求

### 7.1 图片节点编辑态

新建图片节点后默认进入编辑态。

整体布局：

- 节点标题位于卡片外上方：图片节点 + 编号。
- 上方为图片预览/上传区域。
- 右上角或预览区上方提供“上传”按钮。
- 预览区为空时显示图片占位图标。
- 下方为 prompt 与参数面板。

编辑态内容：

- 快捷入口：图生图、图片高清。
- prompt 辅助 chip：风格、标记、聚焦。
- prompt 输入区。
- 底部参数栏。

### 7.2 Prompt 输入能力

placeholder：

`描述你想要生成的画面内容，按 / 呼出指令，@ 引用素材`

输入能力：

- 支持普通自然语言 prompt。
- 支持 `/` 指令入口。
- 支持 `@` 素材引用。
- 支持翻译提示词。
- 支持 prompt 增强或闪电按钮。

Prompt 辅助 chip：

- 风格：帮助用户选择画面风格、艺术风格、摄影风格。
- 标记：帮助用户加入人物、场景、物品、主体等结构化标签。
- 聚焦：帮助用户明确画面主体、构图重点、镜头焦点。

首期可以先做 chip 弹层 UI 与选中状态，后续再接真实 prompt 拼接能力。

### 7.3 图片参数栏

底部参数栏需要包含：

- 模型选择：默认 `Lib Navo Pro` 或 ColaAI 自有模型名。
- 尺寸与清晰度：如 `16:9 · 2K`。
- 摄像机/镜头预设。
- 生成张数：默认 `1张`。
- 联网搜索开关。
- 消耗点数，如 `14`。
- 生成按钮。

验收标准：

- 空 prompt 时生成按钮禁用。
- 输入 prompt 后生成按钮亮起。
- 切换尺寸、张数、模型时消耗点数可以实时变化。
- 联网搜索开关状态清晰。

### 7.4 图片节点浏览态

失焦或生成完成后，图片节点收起为轻量卡片：

- 图片结果占据主要区域。
- 标题保留在卡片外上方。
- 右上角提供小操作按钮。
- 保留“尝试：图生图 / 图片高清”等快捷入口。
- 不展示完整 prompt 面板与参数栏。

目标：

- 让画布保持干净。
- 用户需要编辑时再展开。
- 用户需要后处理时选中结果节点即可。

## 8. 图片结果派生工作流

### 8.1 选中态工具条

图片结果节点被选中后，在节点上方显示横向悬浮工具条。

工具条能力：

- 全景，带 NEW 标记。
- 多角度。
- 打光。
- 九宫格。
- 高清。
- 宫格切分。

工具条设计：

- 深色 pill 容器。
- 图标 + 文字。
- 当前可下拉的工具显示箭头。
- 新能力显示 NEW badge。
- 工具条跟随节点位置，但避免遮挡图片主体。

### 8.2 派生节点行为

用户点击工具条能力后：

1. 系统在图片节点右侧或合适位置创建派生节点。
2. 源图片节点与派生节点之间自动生成连线。
3. 画布平滑 pan/zoom 到新节点附近。
4. 新节点进入编辑态或配置态。

派生节点类型：

- 高清节点。
- 九宫格节点。
- 多角度节点。
- 打光节点。
- 全景节点。
- 宫格切分节点。

首期建议优先级：

- P0：高清节点。
- P1：九宫格节点、多角度节点。
- P2：打光、全景、宫格切分。

### 8.3 高清节点

高清节点用于图片后处理。

配置项：

- 标题：高清。
- 说明：配置参数生成高清图像。
- 模式：高清放大。
- 模型选择：Topazlabs 或 ColaAI 自有高清模型。
- 模型类型：通用。
- 放大倍数：2、4、6、8。

验收标准：

- 从图片结果点击“高清”后自动创建高清节点。
- 高清节点与源图片节点自动连线。
- 高清节点展示配置面板。
- 未接真实能力时可以显示“即将支持”或 mock 状态，但工作流结构必须完整。

## 9. 素材与历史

### 9.1 我的素材

入口：左侧工具栏“我的素材”。

面板结构：

- 我的素材。
- 我的主体库。

分类：

- 全部。
- 其它。
- 人物。
- 场景。
- 物品。
- 风格。
- 音效可保留但图文首期弱化。
- 项目空间。

与图片节点联动：

- 图片 prompt 中输入 `@` 可引用素材。
- 上传图片可以加入素材库。
- 素材可以拖入画布，生成图片资源节点。

### 9.2 历史记录

入口：左侧工具栏“历史记录”。

面板结构：

- 图片历史。
- 视频历史可隐藏或弱化。
- 音频历史可隐藏或弱化。
- 时间降序。
- 批量操作。

图文首期重点：

- 图片历史。
- 选择历史图片作为素材。
- 从历史图片创建图片节点。
- 从历史图片进入图生图或高清流程。

## 10. 动画与切换需求

整体原则：

- 动画服务状态理解，不做炫技。
- 所有动画保持短、轻、顺。
- 优先复刻 Liblib 的“状态变化很顺”，而不是堆特效。

### 10.1 节点创建菜单动画

触发：双击画布或点击添加节点。

动画：

- 从点击点附近出现。
- opacity：0 -> 1。
- scale：0.96 -> 1。
- translateY：6px -> 0。
- 时长：120ms - 180ms。
- easing：ease-out 或 spring-lite。

### 10.2 编辑态展开动画

触发：新建节点、点击节点、点击快捷入口。

动画：

- 小卡片保持位置稳定。
- prompt 面板从卡片下方展开。
- opacity：0 -> 1。
- height / scaleY：折叠 -> 展开。
- translateY：8px -> 0。
- 参数栏随面板延迟 40ms 淡入。

### 10.3 失焦收起动画

触发：点击画布空白区域或选中其他节点。

动画：

- prompt 面板 opacity：1 -> 0。
- 面板轻微下移或缩短。
- 卡片回到浏览态。
- 时长：100ms - 160ms。

### 10.4 选中态工具条动画

触发：选中图片结果节点。

动画：

- 工具条从节点上方滑入。
- opacity：0 -> 1。
- translateY：8px -> 0。
- 工具按钮 stagger 依次出现，每项延迟 20ms - 30ms。
- 离开选中态时整体淡出。

### 10.5 派生节点动画

触发：点击高清、九宫格、多角度等工具。

动画步骤：

1. 源节点工具按钮短暂 pressed 状态。
2. 连线从源节点向目标方向绘制。
3. 目标节点 scale：0.96 -> 1，opacity：0 -> 1。
4. 画布平滑 pan/zoom 到目标节点。

验收标准：

- 用户能明显感知“这个新节点来自刚才那张图”。
- 连线和新节点出现顺序自然，不突然闪现。

### 10.6 生成按钮状态动画

状态：

- Disabled：灰色、低对比、不可点击。
- Ready：亮色、轻微提升、hover 有高亮。
- Loading：显示旋转/脉冲/进度感。

动画：

- 输入 prompt 后按钮 120ms 内变亮。
- Ready 状态可轻微 scale 1 -> 1.02 -> 1。
- 不做过强发光，避免廉价感。

### 10.7 图片结果出现动画

生成结果加载阶段：

- 预览区显示 skeleton 或 shimmer。
- 可显示生成中状态文案。
- 图片加载完成后淡入。

动画：

- skeleton shimmer 低对比。
- 图片 opacity：0 -> 1。
- scale：1.01 -> 1。
- 时长：180ms - 260ms。

### 10.8 参数菜单动画

触发：模型、尺寸、摄像机、张数等按钮。

动画：

- 弹层从按钮附近浮出。
- 当前项高亮。
- opacity + scale + translate。
- 点击外部关闭。

## 11. 状态定义

### 11.1 节点状态

- idle：浏览态。
- selected：选中态，显示边框/连接点/工具条。
- editing：编辑态，显示 prompt 面板与参数栏。
- generating：生成中，显示 loading。
- result：已生成结果。
- derived：由其他节点派生。
- error：生成失败或配置错误。

### 11.2 图片节点状态流

1. create -> editing。
2. editing + empty prompt -> disabled generate。
3. editing + prompt -> ready generate。
4. ready generate -> generating。
5. generating -> result。
6. result + selected -> derivative toolbar。
7. derivative toolbar + action -> create derived node + edge。

### 11.3 文本节点状态流

1. create -> editing。
2. editing + empty prompt -> disabled generate。
3. editing + prompt -> ready generate。
4. ready generate -> generating。
5. generating -> result/summary。
6. result -> can connect to image node。

- prompt 输入后生成按钮状态变化。
- 图片节点底部参数栏。
- 图片结果选中态工具条。
- 高清派生节点。
- 自动连线。
- 核心切换动画：菜单出现、编辑展开、失焦收起、工具条出现、派生节点出现。

### P1：增强体验

- 图片 prompt 的风格/标记/聚焦弹层。
- 模型选择菜单。
- 尺寸与清晰度菜单。
- 摄像机/镜头预设菜单。
- 生成张数菜单。
- 图片历史面板。
- 我的素材面板。
- @ 素材引用 UI。
- 九宫格、多角度派生节点。

### P2：后续扩展

- 全景、打光、宫格切分。
- 批量历史操作。
- 素材库拖拽到画布。
- 真实后处理模型接入。
- 更完整的生成进度与错误恢复。

## 13. 验收标准

### 13.1 功能验收

- 用户可以双击画布创建文本或图片节点。
- 文本节点和图片节点都能在浏览态与编辑态之间切换。
- 输入 prompt 前生成按钮禁用，输入后启用。
- 图片节点可展示模型、尺寸、摄像机、张数、联网搜索、消耗点数。
- 图片结果被选中后出现派生工具条。
- 点击高清后创建高清节点，并自动连线。
- 素材和历史入口可打开对应面板。

### 13.2 动画验收

- 创建菜单不是瞬间闪现，而是从点击位置轻微弹出。
- 编辑面板展开和收起无跳动。
- 工具条出现和消失流畅。
- 派生节点出现时，用户能感知来源关系。
- 连线绘制与节点出现顺序自然。
- 所有动画在低性能设备上不明显卡顿。

### 13.3 视觉验收

- 所有新增和修改的 UI 都符合当前 ColaAI 画布主题，不能直接照搬 Liblib 的品牌视觉。
- 节点、工具条、弹层、参数栏、素材/历史面板在圆角、色彩、阴影、边框、字体层级上保持同一设计语言。
- 画布默认干净，不被参数面板淹没。
- 节点标题、预览、prompt、参数层级清晰。
- 选中态、编辑态、生成态、结果态有明确区别。
- 深色编辑面板或半透明浮层的边框、阴影、hover 状态统一。
- 工具条不会遮挡图片主体。

## 15. 风险与约束

- 动画过多会影响性能，需要限制同时动画数量。
- 如果编辑态面板尺寸过大，可能遮挡其他节点，需要处理自动避让或画布 pan。
- 派生节点自动创建时需要避免覆盖已有节点。
- 素材库和历史记录如果数据为空，需要有空状态设计。
- 未接入真实模型前，需要明确 mock/coming soon 状态，避免用户误以为可以生成。

## 16. 建议实施路径

第一步：完成节点状态与布局骨架。
第二步：完成文本/图片节点编辑态与浏览态切换。
第三步：完成图片结果选中态工具条。
第四步：完成高清派生节点与自动连线。
第五步：补齐动画系统。
第六步：补齐素材库、历史记录、参数菜单与 prompt 辅助 chip。

## 17. 成功指标

- 用户创建图片节点后，能在 3 秒内理解如何输入 prompt 和设置参数。
- 用户看到图片结果后，能自然发现高清/九宫格/多角度等后续动作。
- 单个画布中存在多个节点时，默认视觉仍然清爽。
- 节点切换无明显闪烁、跳动、遮挡。
- 后续接入真实生成能力时，无需重构节点状态与工作流结构。
