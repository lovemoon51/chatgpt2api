# ColaAI 画布交互增强设计

## 目标

在现有 ColaAI 无限画布基础上补齐第一批高频交互能力，让画布从“可拖拽的节点面板”升级为“可顺手编排的创作空间”。这一轮重点解决选择、批量移动、对齐反馈和基础快捷键，不改变当前浅色 ColaAI 视觉和已稳定下来的拖拽性能链路。

## 范围

- 保留当前 `/ColaAI` 下画布模式的全屏沉浸式布局。
- 保留当前默认交互：空白区域拖拽继续用于平移画布。
- 新增 `Shift + 拖拽空白区域` 框选节点。
- 新增节点多选、组拖拽、批量删除、全选、复制与方向键微调。
- 新增节点拖拽时对其他节点的边缘和中心线吸附，并显示临时参考线。
- 不改动当前 AI 生图链路、生成抽屉和本地持久化策略的核心结构。
- 不引入新后端 API，不迁移到第三方白板库。

## 交互决策

### 1. 选择模型

- 单击节点时，保持当前单选行为。
- 单击连线时，保持当前单选连线行为。
- 第一阶段不支持“节点与连线混合多选”，多选仅作用于节点。
- `Shift + 点击节点` 用于将节点加入当前多选，若节点已在多选中，则从多选中移除。
- `Shift + 拖拽空白区域` 进入框选模式，框中的节点成为新的选中集合。
- 未按 `Shift` 时点击空白区域，继续走画布平移逻辑；若只是点击而未移动，则清空当前选区。

### 2. 拖动行为

- 当前没有多选时，拖拽节点行为与现在一致。
- 当前有多选且按下的是任意已选节点时，整组选区一起移动。
- 当前有多选但按下未选中节点时，先切换到该节点单选，再开始拖动。
- 组拖拽时，各节点保留原有相对位置，只计算一次拖拽偏移量并批量应用。
- 拖动期间继续沿用现有 `requestAnimationFrame` 批处理，避免把多选拖动做回卡顿版本。

### 3. 吸附与参考线

- 吸附只在拖拽节点或节点组选区时生效。
- 吸附对象为“未被当前选中的其他节点”。
- 水平方向吸附点：左边缘、水平中心、右边缘。
- 垂直方向吸附点：上边缘、垂直中心、下边缘。
- 命中阈值采用轻量近距吸附，目标是让用户能感觉到“靠齐”，但不会被远距离强拉。
- 命中时显示一条或多条临时横/竖参考线。
- 参考线只存在于拖动中的临时 UI 状态，不写入 store，不持久化到本地存储。
- 第一阶段不做网格吸附，不做智能分布，不做等距提示。

### 4. 快捷键

- `Esc`：取消框选中的拖拽，或清空当前选区。
- `Delete` / `Backspace`：删除当前选中的节点集合；若当前是单选连线，则删除该连线。
- `Ctrl+A`：选中当前画布中的全部节点。
- `Ctrl+D`：复制当前选中的节点，并复制这些节点之间原有的内部连线。
- 方向键：将当前选中节点或节点组按固定步长微调。
- 快捷键只在焦点不在 `input`、`textarea` 等可编辑控件里时生效，避免打断文字输入。

## 复制规则

- `Ctrl+D` 只复制当前选中的节点，不复制未选中的外部节点。
- 若选中节点之间存在连接，则复制对应的内部连接。
- 若某条连接的一端在选区外，则该连接不被复制。
- 复制出的节点整体向右下偏移一小段固定距离，避免与原节点重叠。
- 复制完成后，新复制出的节点成为当前选区，便于用户继续拖动和排布。

## 状态模型调整

当前 `useCanvasStore` 只维护单选，需要扩展为“单选 + 多选共存但互斥”的模型。

建议状态结构调整为：

```ts
type CanvasState = {
  title: string;
  nodes: CanvasNodeData[];
  connections: CanvasConnectionData[];
  viewport: CanvasViewport;
  selectedNodeIds: string[];
  selectedConnectionId: string | null;
  updatedAt: string;
};
```

配套语义：

- `selectedNodeIds.length === 0` 表示没有节点选中。
- `selectedNodeIds.length === 1` 时等价于当前单选节点。
- 只要 `selectedNodeIds.length > 0`，`selectedConnectionId` 必须为 `null`。
- 只要 `selectedConnectionId !== null`，`selectedNodeIds` 必须为空数组。

为了减少改动面，可继续提供 `selectedNode` 这样的派生值，但其来源要改为 `selectedNodeIds[0]`。

## 临时交互状态

以下状态不进入持久化 store，而是保留在 `InfiniteCanvasSurface` 或局部 helper 中：

- 框选是否进行中。
- 框选起点、终点和屏幕矩形。
- 当前拖拽是否进入吸附命中。
- 当前显示的参考线集合。
- 当前拖拽对应的整组选区初始位置快照。

这样可以避免拖动中的高频临时状态写入 React 主状态和 `localStorage`。

## 组件与模块拆分

这一轮继续基于现有自研实现增量扩展，不引入大重构，但会把几类计算抽成小模块，降低 `InfiniteCanvasSurface` 的复杂度。

- `InfiniteCanvasSurface`
  - 增加框选启动、框选更新、框选结束逻辑。
  - 增加组拖拽判定逻辑。
  - 增加快捷键监听入口。
  - 渲染选框和参考线覆盖层。

- `useCanvasStore`
  - 支持多选节点集合。
  - 增加全选、切换选中、批量移动、批量复制、批量删除动作。
  - 保持当前延迟持久化机制。

- `canvas-selection.ts`
  - 负责节点矩形命中计算。
  - 负责将框选矩形转换为选中节点 id 集合。

- `canvas-snapping.ts`
  - 负责计算拖拽选区与其他节点的边缘/中心对齐。
  - 返回修正后的拖拽偏移和参考线描述。

- `canvas-guides.tsx`
  - 渲染拖拽时临时参考线与框选矩形。

## 视觉表现

- 框选框使用 ColaAI 当前浅色体系中的淡紫色描边与低透明填充。
- 多选节点保持当前选中描边风格，但需要确保多节点同时被选中时视觉一致。
- 吸附参考线使用比连接线更清晰的紫色实线，避免与紫色虚线连接混淆。
- 框选层与参考线层为纯覆盖层，不引入额外卡片、毛玻璃或重滤镜，避免重新带来拖拽性能问题。

## 数据与持久化边界

- 节点、连接、视口和选区仍保存在本地画布状态中。
- 参考线、选框和拖动态不持久化。
- 复制节点时沿用现有节点数据结构；若节点包含图片 URL、提示词或任务结果引用，则原样复制这些字段。
- 不在这一轮新增撤销/重做，因此所有复制、删除、移动动作即时生效。

## 错误与边界处理

- 快捷键在文本编辑状态下必须失效，避免方向键和删除键误伤文本。
- 当选区为空时，`Ctrl+D`、方向键移动、批量删除应直接无操作。
- 当框选过程中鼠标释放在画布外，仍应正常收尾并生成最终选区。
- 当多选节点被整体拖动到画布外，不做边界限制，保持当前无限画布自由度。
- 当复制节点后出现与原节点重叠风险时，统一通过固定偏移规避，不引入复杂碰撞排布。

## 测试与验证

自动测试继续使用现有 `bun:test` 体系，重点覆盖：

- `Shift + 点击节点` 的加入/移出多选逻辑。
- 框选矩形命中正确返回节点集合。
- 组拖拽会按统一偏移更新多个节点位置。
- `Ctrl+A` 选中全部节点。
- `Ctrl+D` 复制选区并复制内部连线。
- 方向键微调节点组位置。
- 吸附 helper 在接近对齐边/中心时返回修正偏移和参考线。
- 删除动作对多选节点、单选节点和单选连线三种情况都正确。

浏览器验证必须覆盖：

1. 打开 `/ColaAI` 并进入画布模式。
2. 使用 `Shift + 拖拽` 框选至少两个节点。
3. 拖任意已选节点，确认整组一起移动。
4. 将节点拖近其他节点，确认出现参考线并能吸附对齐。
5. 使用 `Ctrl+A` 选中全部节点。
6. 使用 `Ctrl+D` 复制节点组，并确认复制出的内部连线存在。
7. 使用方向键微调一组节点位置。
8. 使用 `Delete` 删除当前选区。
9. 刷新页面，确认节点和连接状态保留，且临时参考线与框选状态不会残留。

## 验收标准

- 不改变当前“空白拖拽即平移”的基础手感。
- 用户可以通过 `Shift + 拖拽` 完成稳定框选。
- 多选节点可被整组拖动，且拖动手感保持流畅。
- 节点拖拽时能对其他节点的边缘和中心线进行吸附，并显示清晰参考线。
- 第一批快捷键 `Esc`、`Delete`、`Ctrl+A`、`Ctrl+D`、方向键`可用且不干扰文本输入。
- 自动测试、类型检查、lint 和浏览器验证全部通过。

## 非目标

这一轮明确不做以下内容：

- 连线的多选、批量编辑与组拖拽。
- 网格吸附。
- 撤销/重做。
- 剪切/粘贴。
- 节点组合、锁定、缩放选区、旋转。
- 智能分布、等距整理和自动布局。
